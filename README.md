# Quazio

Модульный органайзер для Android и Windows: календарь, финансы, задачи,
привычки и здоровье, аналитика, будильник, менеджер уведомлений и
клавиатура с нормальной автокоррекцией для русского языка — в одном
приложении вместо нескольких.

**Статус:** ранняя разработка. Готовых версий пока нет.

## Принципы

- **Экономия ресурсов.** Одно приложение и одна база вместо нескольких
  программ со своими процессами и синхронизациями.
- **Данные — только у вас.** Без сервера: телефон и ПК синхронизируются
  напрямую по домашней сети, с шифрованием.
- **Приватность.** Клавиатура не выходит в сеть и не хранит набранный текст.
  Никакой рекламы.
- **Модули по выбору.** Включаете только нужное; разрешения запрашиваются
  только для включённых модулей.

## Сборка

Нужны JDK 21 и Android SDK (`ANDROID_HOME`).

```
gradlew build                    сборка и тесты
gradlew :app:android:installDebug   установить на подключённый телефон
gradlew :app:desktop:run         запустить версию для ПК
```
